# Next Chain Integration

To get a consensus within the community around what chain the devs/community should focus on to add next, there is a voting process by node operators.

### How to vote
As a node operator use the following command
```
$ make mimir
=> Enter THORNode Mimir key: NextChainIntegration

=> Enter THORNode Mimir value: <num>
```
